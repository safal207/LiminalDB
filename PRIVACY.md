# Privacy Policy

This project does not intentionally collect or store personally identifiable information (PII) through its source repository.

Standard platform metadata may be processed by third-party services we use (for example GitHub), including usernames, issue content, pull request history, and timestamps.

## Security Reporting

If you disclose sensitive information in a private security report, we use it only for vulnerability triage and remediation, and retain it only as long as needed for responsible disclosure and fix coordination.

## Operational Deployments

Users deploying this software are responsible for their own runtime privacy compliance, data minimization, retention policy, and legal obligations in their jurisdictions.
