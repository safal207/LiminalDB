# Developer Certificate of Origin (DCO)

This project uses contribution-by-submission under the repository license terms and requires Signed-off-by lines for commits contributed via pull requests.

By adding a Signed-off-by line, you certify the Developer Certificate of Origin 1.1:

https://developercertificate.org/

## How to sign off commits

Use:

```bash
git commit -s -m "your message"
```

This adds a line similar to:

```text
Signed-off-by: Your Name <your.email@example.com>
```
